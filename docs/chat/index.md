# Chat mit Element

Es gibt drei Wege sich bei dem Messenger anzumelden. Man kann
alle drei parallel benutzen — dasselbe Konto darf auf beliebig vielen Geräten
angemeldet sein. 

<div class="grid cards drei" markdown>

-   :material-cellphone:{ .lg .middle } __Element X__

    ---

    Die App für **Android und iPhone**.

    [:octicons-arrow-right-24: Einrichten](element-x.md)

-   :material-android:{ .lg .middle } __SchildiChat Next__

    ---

    Ableger von Element X, **nur für Android**.

    [:octicons-arrow-right-24: Einrichten](schildichat-next.md)

-   :material-web:{ .lg .middle } __Im Browser__

    ---

    Ohne Installation, an jedem Rechner.

    [:octicons-arrow-right-24: Anmelden](web.md)

</div>

??? tip "Empfehlung: Element X auf dem Handy, Browser am Rechner"

    Wer nicht vergleichen mag, hört hier auf zu lesen und richtet diese beiden
    ein.

    **Warum Element X:** Es kommt von denselben Leuten wie der Chat selbst,
    erscheint für Android *und* fürs iPhone, bekommt Neuerungen zuerst — und
    bezeichnet sich nicht mehr als Beta, anders als SchildiChat Next.

    **Wann trotzdem SchildiChat Next:** wenn einem die Darstellung von
    Element X nicht gefällt. Es zeigt Nachrichten in Sprechblasen, macht die
    Liste kompakter und hat ein paar Schalter mehr. Das ist Geschmackssache und
    sonst nichts — dafür fehlt dort gelegentlich etwas, das Element X schon
    kann, weil es hinterherläuft.

## Welcher Weg ist der richtige?

| Situation | Weg |
| --- | --- |
| Handy, egal ob iPhone oder Android | [Element X](element-x.md) |
| Handy mit Android, Element X gefällt mir nicht | [SchildiChat Next](schildichat-next.md) |
| Eigener Rechner | [Browser](web.md) |
| Schulrechner, Computerraum, fremdes Gerät | [Browser](web.md) — und hinterher abmelden |

## Die eigene Adresse

Jede Person hat eine Adresse in dieser Form:

```
@kürzel:werkgymnasium.eu
```

Also dasselbe Kürzel wie beim Schulkonto, dahinter ein Doppelpunkt und
`werkgymnasium.eu`. Diese Adresse gibt man weiter, wenn jemand einen finden
soll — sie funktioniert in allen drei Programmen gleich.

## Jemanden finden

In der Suche den Namen oder das Kürzel eingeben. Wenn die Suche nichts findet,
die **vollständige Adresse** von oben eintippen — dann fragt das Programm
gezielt beim Server nach.

## Häufige Fragen

??? question "Sehen Lehrkräfte meine Nachrichten mit?"

    Nein. Private Unterhaltungen sind Ende-zu-Ende-verschlüsselt; auch die
    Administration kann sie nicht mitlesen. Was Lehrkräfte sehen, sind die
    Räume, in denen sie selbst Mitglied sind.

??? question "Ich habe mein Kennwort vergessen."

    Das Kennwort für den Chat **ist** das Schulkonto — es gibt kein eigenes.
    Ein neues Kennwort bekommt man dort, wo man auch für den Schulrechner eines
    bekommt.

??? question "Ich habe ein neues Handy und komme nicht mehr an alte Nachrichten."

    Verschlüsselte Nachrichten kann nur ein Gerät lesen, das dafür freigegeben
    ist. Beim Anmelden auf einem neuen Gerät fragt das Programm deshalb nach dem
    **Wiederherstellungsschlüssel** oder bittet darum, die Anmeldung auf einem
    alten, noch angemeldeten Gerät zu bestätigen.

    Ist beides nicht mehr möglich, bleiben die alten Nachrichten unlesbar — neue
    kommen normal an. Das ist der Preis der Verschlüsselung und lässt sich von
    der Schule aus nicht umgehen.

??? question "Kann ich mich auf mehreren Geräten gleichzeitig anmelden?"

    Ja, beliebig oft. Handy, Rechner, Tablet — die Unterhaltungen sind überall
    dieselben. Nur muss jedes neue Gerät einmal die Verschlüsselung freigeschaltet
    bekommen, siehe die Frage darüber.

??? question "Muss ich mich um Updates kümmern?"

    Die Apps aktualisieren sich über den Store von selbst. Die Browser-Fassung
    ist immer aktuell, weil sie auf dem Server der Schule liegt.

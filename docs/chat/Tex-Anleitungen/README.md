# TeX Anleitungen
Diese Anleitungen wurden mithilfe des Skripts `anleitung-md2tex` erstellt. Dieses wird mit dem Profil `Paul` von der 
Ansible Rolle Desltop Setup ausgerollt.

Der Sinn und Zweck ist einfach: Sollen die SuS etwas ausgedruckt haben, so kann man keine Website nehmen.

Die Vorlage des Skripts liegt in [github](https://github.com/Ithu123/Desktop_Setup).
